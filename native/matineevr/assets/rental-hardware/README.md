FRAMEBUSTER-SOURCE.md attribution. Source archives can be obtained through
steam-frame/download-hardware-assets.py; they are preserved locally but not
needed in the runtime bundle.

Adaptations: meshes separated from source scenes, oriented and placed in metres;
materials baked to shared diffuse, ambient/roughness/metallic and tangent-normal
atlases; cartridge topology simplified for VR shelf display. The open jewel
case cover was folded into a closed rental case. The N64 scene's accessory
meshes are not used as part of its console. Private game artwork is supplied by
the owner's separate library cache, and is not covered by the app source license.

The Game Boy cartridge is prepared as a source family but is not currently
included in the five-console game shelf selector.

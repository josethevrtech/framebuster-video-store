# Super Nintendo Cartridge

By SomeKevin

Source: https://sketchfab.com/3d-models/super-nintendo-cartridge-b2076d8a65d648ff99bf51ca9d5fca2a

License: http://creativecommons.org/licenses/by/4.0/

Runtime adaptation: meshes placed in physical metres; diffuse, roughness, metallic and tangent normal materials baked to a shared atlas. Cartridge topology simplified for VR shelf display. Private game art is applied separately and is not part of these source assets.
